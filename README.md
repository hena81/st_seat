# student-seat

نظام بحث وإدارة مقاعد الطلاب مبني باستخدام Node.js وExpress.

## التشغيل محلياً

1. ثبّت الاعتماديات:

   ```bash
   npm install
   ```

2. انسخ `.env.example` إلى `.env` وعدّل القيم عند الحاجة.

3. شغّل التطبيق:

   ```bash
   npm start
   ```

4. افتح `http://localhost:3000`.

عند التشغيل لأول مرة يُنشأ حساب إدارة افتراضي باسم `admin` وكلمة مرور
`admin123`. غيّر كلمة المرور مباشرة من لوحة الإدارة.

## ملاحظات الأمان

- ملفات الطلاب والمستخدمين والملفات المرفوعة مستبعدة من Git.
- يجب تعيين `SESSION_SECRET` إلى قيمة طويلة وعشوائية في بيئة الإنتاج.
